Gevonden en opgelost tijdens de run (zelfde PR):
- De console nam via USB geen invoer aan (stond op UART0) → `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`.
- De koppelcodes werden niet gelogd → `PrintOnboardingCodes()` na `esp_matter::start()`.
- `esp_matter::factory_reset()` keert terug met `ESP_OK` vóór de herstart; de log meldde ten onrechte "failed" en
  de led ging uit → de taak wacht nu op de herstart.
